Features

不止是宠物，更是你的AI助手

融合虚拟形象与AI能力，让桌面宠物真正能听懂、会思考、能动手

Live2D 虚拟形象

完美兼容所有 Live2D 模型，支持 Cubism 2.0/3.0/4.0。丰富的动作与表情系统，让你的宠物活灵活现。点击不同部位还有惊喜反应。

本地 AI 推理

支持 Ollama 本地大模型运行，对话数据完全不上传，隐私安全有保障。同时兼容 OpenAI、DeepSeek、阿里云百炼等云端 API。

自然语言操作

用自然语言指挥电脑：打开软件、管理文件、执行命令、安装卸载。AI 会理解你的意图并自动执行，无需记忆复杂指令。

Agent 智能体

内置多角色智能体系统，程序员、研究员、文案写手、运维工程师一键切换。支持工具调用、文件读写、多轮推理，真正能干活的 AI。

Quick Start

三步上手，开箱即用

无需复杂配置，下载安装后即可开始使用

01

下载安装

从官网下载最新版本安装包，双击运行安装程序。支持 Windows 10/11 64位系统，安装过程全自动完成。

02

配置 AI 模型

打开 AI 配置页面，选择本地 Ollama 模型或云端 API（OpenAI、DeepSeek、阿里云百炼等）。一键接入预设配置，也可手动添加自定义模型。

03

开始对话

在对话页面与 AI 龙虾交流，支持自然语言操作系统、文件管理、代码编写等。开启 Agent 模式后，AI 可自动调用工具完成复杂任务。

小提示

桌面宠物支持点击互动，不同部位有不同反应。右键宠物可打开快捷菜单，快速切换模型、隐藏宠物或打开设置。
